# Home Assistant Add-on: Yapaia Beat

![Yapaia Beat](logo.png)

UKW- und DAB+-Radio mit einem RTL-SDR Stick – mit Sendersuchlauf, Favoriten,
Senderlogos, RDS/DLS-Informationen, automatischer Senderverfolgung für
unterwegs und einer eigenen Radio-Karte für Lovelace.

Funktioniert komplett offline – ideal für Camper und Wohnmobil.
